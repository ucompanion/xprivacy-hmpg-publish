# 프롬프트 커리큘럼 (분양사이트 제작용)

실제 분양사이트를 만들 때 필요한 프롬프트만 순서대로 정리했습니다. 위에서부터 그대로 따라 하면 됩니다.
`{ }`는 내 값으로 바꿉니다. 파일럿(xPrivacy)의 스킬 기획·계정 연결·사용량 관련 대화는 제외했습니다.

---

## 1. 준비 (착수 직후)

**1-1. 환경설정**
```
퍼블리싱 프로젝트 환경설정 시작
```
사이트명(단지명) · 기술 스택 · 폴더 구조 · 피그마 연결 · 반응형 · 웹접근성 · 가이드/대시보드 · 디자인 시스템 · 감시 프롬프트를 질문에 답하며 진행합니다. (스킬: `publishing-project-setup`)

**1-2. 피그마 연결 확인** (환경설정 4번에서 했다면 생략)
```
피그마 연결과 이미지 다운로드가 되는지 확인해줘 {피그마 URL}
```

**1-3. 작업 규칙 알려두기**
```
공통 컴포넌트는 옵션 사용이 우선이야. 레이아웃·섹션 컴포넌트는 구조를 바꾸지 말고, 그 외 Core 컴포넌트는 옵션 추가로만 수정해줘.
```

---

## 2. 사이트 구조 (메뉴 · 라우팅)

분양사이트는 메인 한 화면에 섹션이 이어지는 구조가 많습니다. 메뉴는 섹션 앵커인지 별도 페이지인지 먼저 정합니다.

```
분양사이트 메뉴 구조를 {사업개요, 프리미엄, 입지환경, 단지안내(배치·평면), 분양안내(일정·청약), 갤러리, 오시는길, 관심고객등록}로 잡아줘.
각 메뉴가 별도 페이지인지 메인의 앵커인지는 {앵커 / 별도 페이지}로 해줘.
GNB, 푸터, 대시보드, pub 라우팅 파일을 모두 만들어줘
```

## 3. 디자인 시스템 (가이드가 있을 때만)

단지 CI(컬러·서체)가 확정된 뒤 진행합니다.

```
{브랜드 컬러 HEX}, {서체}로 doc/guide/PROMPT_GUIDE_FA_COLORS.md, PROMPT_GUIDE_FA_TYPOGRAPHY.md 기준 파운데이션 가이드를 만들어줘
```
```
doc/guide/PROMPT_GUIDE_FA_ELEVATOR.md, PROMPT_GUIDE_FA_UTILITIES.md 기준으로 Elevator, Utilities 가이드를 만들어줘
```
```
doc/guide/PROMPT_BASE_TEMPLATE.md 기준으로 {Button} 컴포넌트 가이드를 만들어줘
```

---

## 4. 분양사이트 공통 컴포넌트

여러 섹션에 반복되는 것만 도메인 컴포넌트로 만듭니다(Core 컴포넌트를 감싸서). 한 번만 쓰는 것은 만들지 않습니다.

**4-1. 관심고객 등록(상담 신청) 폼**
```
관심고객 등록 폼을 만들어줘. 항목은 이름, 연락처, 방문 희망일(선택), 문의 내용(선택), 개인정보 수집·이용 동의(필수)야.
유효성 검사와 제출 완료 알림(AlertModal)까지 넣고, 제출 처리는 {API 주소 / 임시 처리}로 연결해줘
```

**4-2. 고정 상담 버튼** (전화 · 관심고객 등록, 화면 하단 또는 우측)
```
모든 페이지에 고정 상담 버튼을 넣어줘. 전화 연결({대표번호})과 관심고객 등록 폼으로 이동 두 가지야. 모바일은 하단 고정, PC는 우측 고정으로 해줘
```

**4-3. 평면 타입 탭 · 분양일정 · 갤러리**
```
평면 타입별 탭 컴포넌트를 만들어줘. 타입 {59A / 84A / 84B} 선택 시 평면도, 전용·공급면적, 세대수가 바뀌게 해줘
```
```
분양 일정 타임라인(공고 · 특별공급 · 일반공급 · 당첨자 발표 · 계약)을 만들어줘
```
```
갤러리 슬라이더를 만들어줘. 이미지를 누르면 크게 보는 라이트박스, 모바일은 스와이프가 되게 해줘
```

**4-4. 푸터 법정 고지**
```
푸터에 분양사이트 필수 고지를 넣어줘. 시행사 · 시공사 · 분양대행사, 사업자등록번호, 모델하우스 주소·전화, 이미지·CG 유의 문구, 개인정보처리방침 링크야. 내용은 {문구}로 해줘
```

## 5. 페이지 퍼블리싱 (섹션마다 반복)

**5-1. 페이지 전체**
```
{pub/경로} 피그마대로 업데이트 해줘
피시 {피그마 URL}
모바일 {피그마 URL}
```

**5-2. 섹션 하나만**
```
{pub/경로} "{섹션 제목}" 섹션을 피그마대로 업데이트 해줘
피시 {피그마 URL}
모바일 {피그마 URL}
```

**5-3. 문구·줄바꿈만**
```
{pub/경로} {섹션}의 문구와 줄바꿈 처리만 피그마대로 업데이트 해줘
피시 {피그마 URL} / 모바일 {피그마 URL}
```

**5-4. 이미지 교체** (조감도 · 단지배치도 · 평면도 · 투시도처럼 설명 표기가 들어간 이미지)
```
{pub/경로} {섹션} 이미지를 피그마대로 교체해줘. 이미지 위의 표기·배지는 코드로 만들지 말고 이미지에 포함된 통이미지로 처리해줘
피시 {피그마 URL} / 모바일 {피그마 URL}
```
