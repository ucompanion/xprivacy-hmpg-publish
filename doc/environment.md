# 프로젝트 초기 환경 설정 (Environment Setup)

이 문서는 본 프로젝트의 기반 기술 스택 및 초기 환경 설정 정보를 정의합니다.

## 🛠 기술 스택 (Tech Stack)

### 1. 코어 (Core)
- **Library / Framework**: React
- **Language**: TypeScript
  - 정적 타입을 지원하여 코드의 안정성과 가독성을 높입니다.

### 2. 스타일링 (Styling)
- **Preprocessor**: SCSS (Sass)
  - 변수, 믹스인(Mixin), 중첩(Nesting) 등을 활용하여 컴포넌트별로 효율적이고 유지보수하기 쉬운 스타일링을 작성합니다.

### 3. 빌드 도구 (Build Tool)
- **Bundler**: Vite
  - 빠르고 가벼운 개발 서버 구동(HMR)과 최적화된 프로덕션 빌드를 제공하여 개발 생산성을 크게 향상시킵니다.

### 4. 라우팅 (Routing)
- **Library**: `vite-plugin-pages`
- **방식**: 파일 기반 라우팅 (File-based Routing)
  - `src/pages` (또는 지정된 경로) 폴더 내의 파일 구조에 따라 라우트가 **자동으로 생성**됩니다. 
  - 복잡한 `react-router` 설정 파일을 수동으로 관리할 필요 없이, Next.js처럼 직관적인 페이지 관리가 가능합니다.

## 📁 폴더 구조 전략 (Folder Structure)

본 프로젝트는 퍼블리싱 작업과 프론트엔드 개발 작업을 효율적으로 병행할 수 있도록 설계되었습니다.

### 1. 퍼블리싱과 개발 페이지 분리
파일 기반 라우팅(`vite-plugin-pages`)의 특성을 활용하여, `src/pages` 하위에 퍼블리싱 전용 라우트를 분리 구성합니다.

- **디렉토리 구조 예시**:
  ```text
  src/pages/
  ├── pub/                 # 퍼블리싱 작업 전용 공간 (접속 경로: /pub/...)
  │   ├── index.tsx        # 퍼블리싱 메인 페이지
  │   └── login/index.tsx  # 퍼블리싱 로그인 페이지
  ├── index.tsx            # 실제 서비스용 프론트엔드 개발 메인 (접속 경로: /)
  └── login/index.tsx      # 실제 서비스용 프론트엔드 로그인 페이지
  ```
- **협업 프로세스**:
  1. **퍼블리셔**: `src/pages/pub/` 하위에 정적인 마크업과 UI 상호작용(스타일, 단순 이벤트)이 적용된 화면을 완성합니다.
  2. **개발자**: 퍼블리싱이 완료된 페이지를 기반으로, 실제 서비스 경로(`src/pages/`)에 파일을 구성하고 API 통신, 상태 관리(State), 예외 처리 등 비즈니스 로직을 결합합니다.
- **효과**: 개발 중에도 `/pub` 경로를 통해 순수 UI 퍼블리싱 산출물만 별도로 확인 및 컨펌이 가능하며, 동일 파일 수정으로 인한 Git 충돌(Merge Conflict)을 원천적으로 차단합니다.

### 2. 에셋 및 컴포넌트 공통 사용 (Shared Resources)
페이지 작업 공간은 분리하더라도, 기반 자원은 철저히 공유하여 코드의 중복을 막고 일관성을 유지합니다.
- **이미지 (Images)**: 공통 이미지 자원을 한 곳(`src/assets/images` 등)에서 관리하고 퍼블리싱과 개발 모두 동일한 경로를 참조합니다.
- **스타일 (Styles)**: SCSS 변수, 믹스인(Mixin), 초기화(Reset) 및 글로벌 스타일 등은 한 곳에서 통합 관리하여 전체 디자인의 통일성을 유지합니다.
- **공통 컴포넌트 (Components)**: 버튼, 모달, 폼 요소 등 반복해서 사용되는 UI는 공통 컴포넌트(`src/components`)로 분리하여 퍼블리셔가 구조와 스타일을 잡은 형태를 개발자가 그대로 재사용합니다.

## 🚀 로컬 개발 환경 실행 방법

저장소를 클론한 후 아래 명령어를 통해 프로젝트를 실행할 수 있습니다.

```bash
# 1. 패키지 의존성 설치 (Sass 및 라우팅 모듈 포함)
npm install

# 2. 로컬 개발 서버 실행 (Vite)
npm run dev

# 3. 프로덕션 빌드 (배포용)
npm run build
```

> **Tip**: `npm run dev` 로 개발 서버가 실행된 후, 브라우저에서 아래 경로로 접속하여 정상 동작을 확인하세요.
> - **프론트엔드 메인**: [http://localhost:5173/](http://localhost:5173/)
> - **퍼블리싱 전용 메인**: [http://localhost:5173/pub](http://localhost:5173/pub)
