# xPrivacy 홈페이지 퍼블리싱 (xprivacy-hmpg-publish)

xPrivacy 웹 서비스 퍼블리싱 가이드 및 화면 산출물 관리 저장소입니다.

---

## 📌 프로젝트 개요
- **프로젝트명**: xPrivacy 홈페이지 퍼블리싱
- **설명**: xPrivacy 웹 서비스의 디자인 시스템, 컴포넌트 가이드 및 퍼블리싱 화면 관리

---

## 🛠 기술 스택
- **Core**: React 19, TypeScript
- **Build Tool**: Vite
- **Routing**: React Router
- **Style**: SCSS (Sass)

---

## 📁 주요 디렉토리 구조 (예정)
```text
src/
├── assets/          # 정적 리소스 (스타일, 이미지, 폰트 등)
├── components/      # 공통 컴포넌트 (Core, Preset 등)
└── pages/           # 화면 및 가이드 페이지
    ├── guide/       # 디자인 시스템 및 컴포넌트 가이드
    └── pub/         # 퍼블리싱 목업 화면
```

---

## 🚀 시작하기

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

### 3. 프로덕션 빌드
```bash
npm run build
```
